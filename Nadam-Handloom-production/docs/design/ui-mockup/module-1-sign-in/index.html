Decided

What this mock-up follows

  • Android and iOS, phone and tablet. No browser version for now.
  • Signed in for 7 days, renewed on every use. No idle lock, no surprise logouts.
  • Unfinished work is kept on the phone and comes back after signing in.
  • Owner invites; SMS code on first setup and on any new phone; 6-digit PIN; Face ID or fingerprint.
  • 5 wrong PINs lock sign-in: 15, then 30, then 60 minutes. Forgot PIN unlocks.
  • PIN shown as dots; tries counted per number; logout asks first; every sign-in logged.
  • No "switch user": only the owner runs the counter tablet.
  • SMS: Message Central sends and checks the codes. Codes last 60 seconds, as decided earlier.
  • Design (11 Oct): auto theme, Peacock colours, Plus Jakarta Sans, soft corners, woven header, PIN boxes, floating tab bar.
Answered 11 Oct

Decisions from review

  • JWT: a 15-minute key renewed silently inside a 7-day sign-in. The user never sees it.
  • Change PIN: kept.
  • Lock steps: 15 → 30 → 60 minutes.
  • Database toolkit: Prisma.
  • Server slow / down and "Signed out for safety" messages added.
Fixed from the old app

Content and behaviour fixes

  • "Please use the registered mobile number" told outsiders which numbers exist. Now every reply is generic until the SMS code is verified.
  • PIN digits were visible while typing. Now dots, with a Show button.
  • After a lock ended, one wrong PIN locked it again. Now 5 fresh tries.
  • All phones on the shop Wi-Fi shared one try limit. Now it's per mobile number.
  • Log out had no confirmation and disappeared when the profile failed to load. Both fixed.
  • The invite screen promised an SMS that never came. The new wording only promises what happens.
Planned for later

Not in this module

  • Inviting and removing staff, and signing out their devices: Module 2 (Roles and team).
  • Force update and maintenance screens: Module 11 (Settings).
  • Home, Orders, Scan and Products content: Modules 4–8. Shown here as placeholders.
  • Browser / Windows version: dropped for now.

Excluded from Module 1: decide at the very end

  • If the owner loses their phone number completely, how do they get back in? (Suggested: a second owner account as backup, plus a written reset process.)
  • Optional security extras: an in-app alert to the owner when an account is locked or a new phone is added; hiding the app's screen in the phone's app switcher.
