The building blocks

One set of colour tokens drives light and dark mode. Change the palette, font, corners or theme in Design options and every block below updates. These are the pieces every later module will reuse.

Colours

Tokens for the palette you have picked, in the current theme. Text colours pass contrast on their backgrounds; accent colours are used for highlights, not long text.

The three palettes

A · Indigo Loom
Indigo dye with turmeric thread. Calm, trustworthy, classic handloom colours.
B · Peacock
Peacock teal with copper. Fresh and distinctive.
C · Rani & Charcoal
Charcoal with rani pink. Modern and bold.

Type scale

Headings use the display font; everything else the body font. The monospace is for small labels, codes and numbers.
