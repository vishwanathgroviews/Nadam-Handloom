Fixed from the old app

Behaviour fixes

  • An invoice's page shows every saree, not only the totals.
  • Search by number, name, mobile or tag.
  • Dates are India time everywhere; "7 days" no longer means 8; custom dates start at midnight.
  • "All time" no longer prints only this month; the list and the summary always agree.
  • Staff can no longer download the money totals.
  • An invoice can be made later; a wrong name can be corrected; Excel for the accountant.
  • Cancelled invoices are listed but never counted.
