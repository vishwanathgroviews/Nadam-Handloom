How to review

Four things to try

Open the Design options panel (bottom right) at any time.

Read the day

Open Activity: Today, Yesterday, Sat 10 Oct, each action in one sentence. Important ones are marked amber.

Find the typo

Tap "System Admin changed the store price of Gap Border bramini sarees: ₹3,800 → ₹54,310". That one is real.

Narrow it down

Pick a kind, open Filters (person, period, Important only), or search NH2264.

Compare

Switch "List" (rows / timeline) and "Filters" (chips / one sheet). See the security alert on Home.
