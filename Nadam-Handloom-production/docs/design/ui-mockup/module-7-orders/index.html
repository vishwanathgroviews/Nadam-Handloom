How to review

Four things to try

Open the Design options panel (bottom right) at any time. Your changes stay in this browser until you press Reset demo.

Ship an order

Open Orders → Padma's order (waiting 2 days) → Ship → "Scan a label" → Mark shipped → Open WhatsApp.

Catch a mistake

Ship another order and press "Scan a label already used": it's refused, naming the other order. Change a tracking number on a shipped order.

Finish and cancel

Mark a shipped order delivered. As owner, cancel an online order not yet shipped (refund note).

Follow up

Unpaid checkouts: 4 customers tried 18 times. Switch to Ravi · Staff to compare.

Behaviour fixes

  • Channel badges, search, oldest first, a count on the Orders tab.
  • A tracking number can't go on two orders; a wrong one is changed with a record.
  • Orders can be marked delivered; Shipped no longer grows forever.
  • Owners can cancel an order not yet shipped.
  • Unpaid checkouts are visible to owners.
  • The ship-to card has no blank lines; the message uses the customer's name.
