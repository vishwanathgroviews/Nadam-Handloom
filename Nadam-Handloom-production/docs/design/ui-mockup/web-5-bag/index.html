Website module W5 · mock-up

The bag

Collect sarees in one place, choose how many from a set, see the total, and send the whole bag to the shop on WhatsApp (online payment comes next, in W6). Built in the live website's own look, with real sarees, codes, prices and photos from the live data of 16 Oct.

Open the website mock-up Design kit Device preview

The plan with every rule and decision: docs/modules/web-03-cart.md

How to use it

  1. Open any screen below. Click around: add sarees, change how many, remove, send on WhatsApp, sign in and out.
  2. Press Design options (bottom left). Try the lettered choices; A is my recommendation for each.
  3. In the same panel, Screen states shows every state of the screen you are on (empty, sold out, offline…).
  4. Press Copy my choices and send them on WhatsApp or by email. Nothing is built in the real website before your picks.

Content fixes in this mock-up

  • Names repeat (a saree's name is its collection's), so every bag line shows the code and the photo.
  • Counts say pieces, not "sarees": dress materials (94) and a lehanga set are sold too.
  • The saree page's "Ordering and delivery" text explained WhatsApp only; it now explains the bag.
  • The old address /cart goes to the shop list today; with W5 it goes to the bag.
  • The old bag's "Your cart is empty" had no way forward; the new one offers New in, Collections and Sets.
  • "Call" moves to a small line under the buttons, so "Add to bag" leads.
  • Still to fix in the admin app: "Gap Border bramini sarees" at ₹25,888 (probably a typo) would show in bags.
