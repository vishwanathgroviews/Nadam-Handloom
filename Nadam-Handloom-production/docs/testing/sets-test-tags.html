Test tags for sets (one photo, several tags)

Scan these from this screen with Nandam Admin, Android build 28. They are test tags (TEST01…), not real shop tags. Turn the laptop brightness up and hold the phone about a hand's width from the screen.

This is the real shop. Sarees you save go on the website. Use any subcategory, then delete each test saree when done (Delete frees its TEST tags, so you can use them again).

Test 1: a set of 5 in a batch

  1. Products → a subcategory → Add products → Choose photos → pick 3 photos → Next.
  2. Photo 1 (one saree): scan TEST06. It moves to photo 2 by itself.
  3. Photo 2 (the set): tap + until "Sarees in this photo" says 5, then scan TEST01 to TEST05. After the 5th it moves to photo 3.
  4. Photo 3: scan TEST07. The check screen opens: photo 2 shows its 5 tags, "Save 7 sarees · 3 photos".
  5. Save. Then open the set: it says "Set of 5 · 5 in stock".

The set of 5

Scan these five on the same photo, after setting "Sarees in this photo" to 5.

Single sarees

One tag each: the photo moves on by itself.

Test 2: mistakes the app should catch

  1. Same tag twice: while on the set's photo, scan TEST01 again → "already on this photo".
  2. A second tag on a one-saree photo: on photo 1 (has TEST06), scan TEST11 → it asks Replace, or "A set: keep both".
  3. One more than counted: tap photo 2 (the set, 5 of 5) in the strip, then scan TEST12 → "Make it a set of 6?".
  4. Tag on another photo: on photo 3, scan TEST06 → "Already used in this batch".
  5. Short set: set a photo to 5, scan only 3, tap Review → Save → it asks "Scan the other 2" or "Save it as a set of 3".
  6. After saving: start a new batch and scan TEST01 → "already used" (it's on the saved set).

Extra tags (for Test 2 and Test 3)

TEST11 and TEST12 for the mistake checks; TEST08 to TEST10 for "Add more tags".

Test 3: Add more tags later

  1. Open the saved set (Set of 5) → Add more tags (same design).
  2. Scan TEST01 → "already on this saree".
  3. Scan TEST08, TEST09, TEST10 → "Add 3 tags · set of 8" → it says "Set of 8 · 8 in stock".
  4. Tap one tag → its own actions (Change tag, Tag damaged, Saree damaged, Remove this tag).
  5. When finished: Delete saree on each test saree. All TEST tags become free again.

Quick add a set (optional)

Subcategory → Quick add → take a photo → tap + to 3 → scan TEST01, TEST02, TEST03 (after deleting the batch test, or use TEST13–TEST15 below).
