# Project Rules & Guidelines

## Git Branch, Commit & Push Rules
- **NEVER push anything to `main` (`origin/main`).**
- **Target Branch**: If anything needs to be pushed, push it **only to `dev/sasi`**.
- **No Automatic Commits or Pushes**: NEVER automatically commit or push anything.
- **Explicit Permission Required**: ALWAYS ask the user for permission first before committing or pushing, and proceed ONLY upon receiving their explicit confirmation and instruction.
